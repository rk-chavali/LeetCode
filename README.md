# LeetCode

Solutions to LeetCode problems, one directory per problem, named by the problem's
own number and slug so a solution is easy to find by ID.

[![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white)](https://www.java.com/)
[![C++](https://img.shields.io/badge/C++-00599C?logo=cplusplus&logoColor=white)](https://isocpp.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-22C55E.svg)](LICENSE)

## Layout

```
0001-two-sum/
  0001-two-sum.java     solution
  README.md             problem statement
  NOTES.md              approach and complexity
```

Solutions are in whichever language suited the problem, mostly Python with some
Java, C, and C++.

## Index

| Range | Problems |
|-------|----------|
| Easy warmups | Two Sum, Reverse Integer, Majority Element, Contains Duplicate, Perfect Number |
| Arrays and sorting | Sort Colors, Merge Sorted Array, Kth Largest Element |

Directories are numbered, so browsing in order tracks roughly the order they were
solved.
